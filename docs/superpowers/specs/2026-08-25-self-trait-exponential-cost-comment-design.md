# 玩家自身词条指数消耗说明修复设计

## 问题

玩家自身词条的指数消耗模式在服务端扣除、GUI 提示和卸载退款中统一采用 `2^当前等级`。从 0 级开始升级时，消耗依次为 `1、2、4、8……`。

`L2HConfig` 的配置注释却写成 `2^(当前等级 - 1)`。该公式会描述成 `1、1、2、4……`，并且在当前等级为 0 时产生不可能使用物品数量表达的 `0.5`，与实际行为不一致。

## 目标行为

- 保留现有指数消耗序列 `1、2、4、8……`。
- 配置说明改为 `2^当前等级`，并直接列出序列示例。
- 服务端扣除、GUI 提示、单级卸载退款和全部卸载退款逻辑均不修改。
- 添加回归检查，确保错误公式不再出现在该配置说明中。

## 设计

只修改 `L2HConfig.Common` 中 `playerSelfTraitCostMode` 的注释，将指数模式说明改为：

`3 = 指数: 消耗 2^当前等级 个（依次为 1、2、4、8……）`

在现有配置测试中读取 `L2HConfig.java` 源码，断言新的完整说明存在，并断言旧公式 `2^(当前等级 - 1)` 不存在。该测试只保护配置文案，不对正确的运行逻辑做无关重构。
