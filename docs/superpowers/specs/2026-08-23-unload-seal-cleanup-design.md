# 卸载封印元数据清理设计

## 问题

单级、整组和全部卸载只删除封印到期时间，没有删除 `l2htweaks_sealed_level_<词条ID>`。卸载后的词条等级或存在状态已经改变，但 `isDisabled()` 仍会依据残留键判断为封印，后续解封可能恢复旧等级并造成返还物复制。

## 行为

- 卸载任意词条等级后，同时删除该词条的封印等级和封印到期时间。
- 单级卸载后保留的新等级保持正常生效，不再携带旧封印状态。
- 整组和全部卸载后不保留任何对应封印元数据。
- 返还数量、词条初始化、生命值比例和能力同步顺序保持不变。

## 实现边界

在 `TraitDisableHelper` 中增加接收 `CompoundTag` 和词条 ID 的 `clearSealData` 方法。三种卸载路径以该方法替换现有的单键删除，不通过完整解封流程，避免恢复旧等级和额外同步。

## 验证

单元测试在同一个 `CompoundTag` 中预置封印等级和到期时间，调用清理方法后断言两者均不存在。随后检查三种卸载路径全部调用统一方法，并运行完整 `clean build`。
