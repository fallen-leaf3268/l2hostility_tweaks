# 玩家潜影贝友方目标过滤设计

## 问题

`ShulkerTraitMixin` 为玩家实现了视线锥形自动选靶，但候选条件只有“是存活的生物”。同队玩家、同盟实体和玩家拥有的宠物或召唤物都可能因距离更近而被选为 `HostilityBullet` 的最终目标。子弹命中路径会直接造成伤害，因此后续的扩展碰撞过滤无法撤销错误锁定。

## 设计

在距离、夹角和评分之前排除友方候选：

- 候选实体认为玩家是盟友时排除；
- 玩家认为候选实体是盟友时排除，兼容只实现单向同盟判断的模组实体；
- 候选实现 `OwnableEntity` 且所有者 UUID 等于玩家 UUID 时排除；
- 其他存活生物继续参与原有视线、20 格距离和评分逻辑，中立生物仍可被玩家主动瞄准；
- 不修改生物持有潜影贝词条时使用原版仇恨目标的逻辑，也不修改子弹伤害和射击间隔。

将三个友方事实合并为包内可测试的纯判定方法。实体关系和所有者 UUID 在选靶循环中读取，纯方法只决定候选是否允许。

## 验证

回归测试覆盖：

1. 双方均非同盟且不属于玩家时允许选中；
2. 候选认为玩家是同盟时拒绝；
3. 玩家认为候选是同盟时拒绝；
4. 候选由玩家拥有时拒绝。
