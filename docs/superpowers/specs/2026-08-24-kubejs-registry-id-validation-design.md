# KubeJS 词条注册表 ID 安全校验设计

## 目标

修复 KubeJS 自定义词条在药水或属性 ID 格式错误、目标未注册时的延迟异常，同时保持所有合法脚本的现有行为不变。

## 已确认根因

四个 Builder 直接通过 `new ResourceLocation(...)` 解析脚本字符串。格式错误会抛出异常；`legendary_attribute` 还把属性查询保存在 Supplier 中，导致错误延迟到怪物初始化或 Tooltip 渲染时才出现。合法但未注册的属性 ID 会返回 `null`，随后在属性应用或说明生成时触发空指针。

`legendary_effect` 同样把药水解析放在按等级执行的函数中，因此错误可能在每次攻击或 Tooltip 计算时重复出现并反复记录日志。

## 设计

新增一个范围受限的 KubeJS 注册表解析辅助类，在 Builder 配置阶段完成一次性解析和查询：

- 药水 ID 使用安全解析；格式错误或未注册时返回空结果。
- 属性 ID 使用安全解析；格式错误或未注册时返回空结果。
- 辅助类不持有缓存，不改变注册表生命周期，只负责把异常输入转换为明确的空结果。

各 Builder 使用该结果建立稳定状态：

- `self_effect` 与 `legendary_self_effect`：无效药水 ID 时保留默认虚弱效果，并记录一次错误。
- `legendary_effect`：无效药水 ID 时建立一次默认虚弱效果函数，不在攻击或 Tooltip 阶段重复解析、重复记录。
- `legendary_attribute`：无效属性 ID 时不添加该属性条目，并记录一次错误。
- 有效 ID 在配置阶段解析为实际注册对象，后续 Tooltip 与战斗逻辑直接使用该对象。

## 错误处理

错误日志包含注册表类型和原始 ID，便于定位 KubeJS 脚本。无效输入不会中止整批脚本重载，也不会把 `null` 传入词条对象。

不为错误属性建立虚假替代属性，因为这会产生与脚本意图无关的数值效果；跳过单条错误属性是最小、安全的退化方式。药水 Builder 已有虚弱默认值，因此继续使用该默认值。

## 测试

通过纯解析辅助接口覆盖以下行为：

1. 格式错误的资源 ID 不抛异常并返回空结果。
2. 合法且已注册的药水和属性能够解析成功。
3. 合法但未注册的 ID 返回空结果。
4. Builder 的源代码回归检查确认不再包含来自脚本字符串的 `new ResourceLocation(...)` 延迟解析。
5. 运行全量 `clean build`，确认现有测试、资源校验和 JAR 构建全部通过。

## 非目标

- 不更改有效 KubeJS 脚本的效果、数值、颜色或 Tooltip 文案。
- 不新增配置项或运行时依赖。
- 不调整其他注册表 ID 的处理逻辑。
- 不部署 JAR 到 `mods` 目录。
