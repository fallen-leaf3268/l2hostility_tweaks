# 封印词条激活语义设计

## 问题

封印词条以负等级保存在 `MobTraitCap.traits` 中。现有 Mixin 把负等级的 `hasTrait()` 结果改为 `true`，导致部分上游逻辑绕过通用过滤器后仍把封印词条当作生效词条。例如封印的分裂会阻止不死词条复活，封印的主宰仍可能进入主宰专用逻辑。

## 设计

- 原始等级大于 0：词条存在且生效。
- 原始等级等于 0：词条不存在。
- 原始等级小于 0：词条存在于存档中，但不生效。
- `getTraitLevel()` 对非正等级返回 0。
- `hasTrait()` 对非正等级返回 `false`。
- Tooltip、解封、升级和卸载继续直接读取原始映射，不改变封印数据。

## 验证

添加单元测试覆盖正、零、负等级的激活判定，再运行定向测试和完整 `clean build`。
