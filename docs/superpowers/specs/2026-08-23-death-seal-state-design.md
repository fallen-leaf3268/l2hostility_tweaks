# 死亡后封印状态恢复设计

## 问题

玩家死亡克隆会恢复 `MobTraitCap.traits` 中的负等级，并单独恢复封印到期时间，却不会恢复 `l2htweaks_sealed_level_<词条ID>`。`TraitDisableHelper.isDisabled()` 和解封流程依赖该键，因此重生后的负等级词条无法被正常识别和自动解封。

## 权威数据

死亡快照中的原始词条等级是恢复依据：负等级表示封印，绝对值表示恢复等级；正等级表示正常生效。封印等级 NBT 是由该数据派生的运行时元数据，不作为第二份独立权威数据。

## 行为

- 恢复负等级词条时，写入对应的封印等级 NBT，值为原始等级的绝对值。
- 恢复正等级或零等级词条时，删除同词条可能存在的陈旧封印等级 NBT。
- 现有封印到期时间快照和恢复方式保持不变。
- 不改变 `keepInventory=false` 时清除玩家词条的行为。

## 实现边界

在 `TraitDisableHelper` 中提供一个接收 `CompoundTag`、词条 ID 和原始等级的同步方法，由 `onPlayerClone` 在初始化每个恢复词条前调用。该方法只管理封印等级键，不处理到期时间、能力同步或词条初始化。

## 验证

单元测试直接使用 `CompoundTag` 覆盖负等级重建和正等级清理，然后运行完整 `clean build`。
